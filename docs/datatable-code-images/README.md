# DataTable Code Images

These SVG files show practical `DataTable` usage patterns from the project:

- `01-datatable-basic.svg`: basic import, columns, data, and render
- `02-datatable-options.svg`: optional props like `searchable`, `defaultPageSize`, and `pageSizeOptions`
- `03-datatable-actions.svg`: `titleButton`, `renderRowActions`, `getRowClassName`, and `isLoading`
- `04-datatable-row-click.svg`: `hidden`, `onlyAdmin`, and `onRowClick`

You can open them directly in a browser or import them into design tools.
